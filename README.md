# Distribuidora Graser

Plataforma web de catálogo y carrito → WhatsApp para una tienda de electrónica y electricidad.

> No es ecommerce con pago online. El cliente arma su consulta y la venta se cierra manualmente por WhatsApp.

## Stack

- Next.js 15 (App Router) · TypeScript · TailwindCSS · shadcn/ui
- Zustand (carrito) · NextAuth (admin) · React Hook Form + Zod
- Google Sheets API (datos) · Cloudinary (imágenes) · Framer Motion
